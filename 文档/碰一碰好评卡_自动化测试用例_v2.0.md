## 1. 测试概述与环境

### 1.1 系统架构

| 层级 | 技术栈 | 端口 |
|------|--------|------|
| 管理后台前端 | Vue 3 + Ant Design Vue + Vite | 5173/5174 |
| 后端服务 | Spring Boot + MyBatis + MySQL | 8222 |
| C端小程序 | uni-app (H5) | 5175 |
| 数据库 | MySQL 5.7 (远程) | 3306 |

### 1.2 角色体系

| 角色 | 标识 | 权限范围 |
|------|------|---------|
| 超级管理员 | `super_admin` | 全部功能，含系统配置、用户管理、商家权限配置 |
| 管理员 | `admin` | 商家、设备、营销、AI 等业务模块 |
| 商家 | `merchant` | 自身商家信息、设备、AI创作、营销配置 |

### 1.3 测试环境变量

```yaml
env:
  base_url: "http://localhost:8222"           # 后端 API 基地址
  admin_url: "http://localhost:5173"           # 管理后台前端地址
  c_url: "http://localhost:5175"               # C端 H5 地址
  timeout: 15000                               # 默认超时(ms)
  test_admin_username: "test_admin"            # 测试管理员账号
  test_admin_password: "Test@123456"           # 测试管理员密码
  test_super_admin_username: "super_admin"     # 测试超管账号
  test_super_admin_password: "Super@123456"    # 测试超管密码
```
