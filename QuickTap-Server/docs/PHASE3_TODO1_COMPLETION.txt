CONFIGURATION & SETUP
═══════════════════════════════════════════════════════════════════════════════

To enable real OpenAI API integration, add to application-prod.yml:

```yaml
ai:
  openai:
    enabled: true
    api-key: ${OPENAI_API_KEY}  # Set via environment variable
    api-url: https://api.openai.com/v1
    model: gpt-3.5-turbo
    timeout: 30000
    max-tokens: 2000
    temperature: 0.7
```

Environment Variables:
  OPENAI_API_KEY: Your OpenAI API key (from openai.com)

If API key is not provided:
  - Application logs a warning
  - Falls back to MockOpenAiClient
  - All functionality works with mock data
  - Perfect for development/testing
