> 版本：v1.6.0 ｜ 更新日期：2026-08-03 ｜ 技术栈：Spring Boot 3.1.5 + Java 17

---

## 一、项目概述

QuickTap Server 是一套面向线下商户的智能营销中台后端服务，核心业务为：商家入驻审核 → 生成/绑定二维码与 NFC 设备 → 后台配置 C 端展示内容（轮播图、卡券、推广平台、WiFi 等）→ C 端小程序扫码触达用户。

### 1.1 角色体系

| 角色 | 标识 | 权限范围 |
|------|------|----------|
| 超级管理员 | `SUPER_ADMIN` | 全系统管理权限，含角色分配、商户删除、系统配置 |
| 管理员 | `ADMIN` | 商户审核、设备管理、订单管理、统计查看；可被限定访问部分商户 |
| 商户 | `MERCHANT` | 仅操作自己名下的资源（设备、卡券、语料、推广配置等） |
| 普通用户 | `USER` | C 端小程序用户，领券、扫码、绑定设备 |

### 1.2 核心业务流程

```
┌─────────────────────────────────────────────────────────────────────┐
│                      商家入驻流程                                     │
├─────────────────────────────────────────────────────────────────────┤
│  1. C端扫码 → /api/miniapp/merchant/check-bind 检查设备是否已绑定     │
│  2. 未绑定 → /api/miniapp/merchant/register 提交入驻资料              │
│     - 创建 merchant (status=0 待审核, audit_status=0)                │
│     - 创建 admin (role=merchant, status=0 待审核，审核前无法登录)     │
│     - 绑定 device/qrcode 的 merchant_id                              │
│  3. 后台审核 → PUT /api/merchant/{id}/approve                        │
│     - merchant.status=1, audit_status=1                              │
│     - 同步启用关联 admin 账号 (status=1)                              │
│  4. 商家登录后台 → 配置 C 端内容（轮播图、卡券、推广平台等）           │
└─────────────────────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────────────────────┐
│                      设备与二维码模型                                  │
├─────────────────────────────────────────────────────────────────────┤
│  - 一套设备 = 两条 device 记录 (type=qrcode + type=nfc)              │
│  - 共用同一个 systemCode（设备套的唯一标识）                           │
│  - 商家注册时通过 code（二维码/NFC编码）绑定 merchant_id               │
│  - 设备列表按 name + systemCode 分组展示为一套                         │
│  - C端扫码后通过 systemCode 找到 merchant_id，展示对应商家页面         │
└─────────────────────────────────────────────────────────────────────┘
```

## 二、技术架构

### 2.1 技术栈

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 基础框架 | Spring Boot 3.1.5 | Java 17 |
| 安全框架 | Spring Security 6 + JWT | 无状态认证，Token 黑名单 |
| 持久层 | MyBatis 3 + PageHelper | XML 映射，动态 SQL |
| 数据库 | MySQL 8.0 | utf8mb4 编码 |
| 缓存 | Redis（可选） | 未启用时降级为 JVM 本地缓存 |
| 消息队列 | Kafka | 异步事件处理 |
| 分布式事务 | Seata 1.7（可选） | 支付联调场景 |
| API 文档 | Knife4j / Swagger | `/doc.html` |
| 构建 | Maven | |

### 2.2 分层架构

```
controller/      接口层：HTTP 路由、参数校验、权限注解
   ↓
service/         业务层：业务逻辑、事务管理、越权校验
   ↓
mapper/          数据层：MyBatis 接口 + XML 映射
   ↓
entity/          实体层：数据库表对应实体
dto/             传输层：请求/响应 DTO
security/        安全层：JWT 过滤器、UserDetailsService、所有权校验
config/          配置层：Security、Redis、Kafka、环境校验
exception/       异常层：全局异常处理
```

### 2.3 安全机制

| 机制 | 实现 |
|------|------|
| 认证 | JWT Token，有效期 2 小时，支持 `/api/refresh-token` 刷新 |
| 授权 | `@PreAuthorize` 方法级 + SecurityConfig URL 级双重控制 |
| 越权防护 | `OwnershipChecker` 校验 MERCHANT 角色只能操作自己名下资源 |
| 密码加密 | BCrypt |
| CORS | SecurityConfig 统一配置白名单源 |
| CSRF | JWT 无状态 API，禁用 CSRF |
| 敏感信息 | 环境变量注入，`EnvironmentValidator` 启动校验生产配置 |

### 3.1 核心表（11 张）

| 表名 | 说明 | 关键字段 |
|------|------|----------|
| `admin` | 管理员/商家账号 | id, username, password(bcrypt), role, merchant_id, status |

## 六、部署与运行

### 6.1 环境要求

- JDK 17+
- MySQL 8.0+
- Maven 3.6+
- Redis 7+（可选）
- Kafka（可选）

### 6.2 数据库初始化

```bash
# 1. 创建数据库
mysql -u root -p -e "CREATE DATABASE quicktap_dev DEFAULT CHARSET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# 2. 执行基础初始化
mysql -u root -p quicktap_dev < src/main/resources/db/init.sql

# 3. 按版本顺序执行升级脚本
mysql -u root -p quicktap_dev < src/main/resources/sql/upgrade_1.1.0.sql
mysql -u root -p quicktap_dev < src/main/resources/sql/upgrade_1.2.0.sql
mysql -u root -p quicktap_dev < src/main/resources/sql/upgrade_1.3.0.sql
mysql -u root -p quicktap_dev < src/main/resources/sql/upgrade_1.4.0.sql
mysql -u root -p quicktap_dev < src/main/resources/sql/upgrade_1.5.0.sql
mysql -u root -p quicktap_dev < src/main/resources/sql/upgrade_1.6.0.sql
```

### 6.3 编译与启动

```bash
# 编译
mvn compile -DskipTests

# 打包
mvn package -DskipTests

# 启动（开发环境）
java -jar target/quicktap-server-1.0.0.jar --spring.profiles.active=dev

# 启动（生产环境）
DB_PASSWORD=xxx JWT_SECRET=xxx ENCRYPTION_KEY=xxx \
java -jar target/quicktap-server-1.0.0.jar --spring.profiles.active=prod
```

### 6.4 访问

- 服务端口：`8222`
- API 文档：`http://localhost:8222/doc.html`
- 健康检查：`http://localhost:8222/api/health`
